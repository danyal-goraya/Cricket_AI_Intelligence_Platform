# Cricket AI — Intelligent Cricket Analytics Platform

A full-stack machine learning platform for cricket analytics, combining classic ML, computer vision, and real-time data-driven simulation — built on 3,517 international T20 matches spanning 100+ countries and 20+ years.

**Live Demo:** [cricket-ai-intelligence.vercel.app](https://cricket-ai-intelligence.vercel.app)
**API:** [cricket-ai-intelligence.onrender.com](https://cricket-ai-intelligence.onrender.com)

> Note: the backend runs on a free-tier server that sleeps after inactivity — the first request may take 30–50 seconds to wake up.

---

## Overview

Cricket AI is an end-to-end analytics platform that turns raw ball-by-ball match data into eight live, interactive tools — from real-time win probability prediction to AI-powered batting shot classification. Every prediction shown is generated by a real, trained model responding live, not a lookup table.

Built solo over a summer, covering the full pipeline: data engineering, model training and evaluation, computer vision, backend API design, frontend development, and production deployment.

---

## Features

### 🏏 Win Predictor
Enter any run-chase situation — runs needed, balls remaining, wickets in hand — and get a live win probability from a gradient-boosted model (XGBoost) trained on 362,000+ real match situations. **92% AUC, 83% accuracy** on held-out test data.

### 🔁 Match Replay
Pick any real match and watch win probability swing ball-by-ball exactly as it happened, with auto-detected "turning points" — the single biggest momentum swing in the match, identified automatically by the model.

### 🎯 AI Shot Coach
Upload a batting photo and get instant shot classification — drive, leg-glance/flick, pull, or sweep — powered by a computer vision pipeline: MediaPipe pose estimation → joint-angle feature engineering → custom PyTorch neural network. **87% accuracy** across 3,600+ labeled images.

### 📊 Player Analytics
A full scouting report for any of 1,700+ players: phase-wise performance (powerplay/middle/death), boundary and dot-ball risk profiles, historical head-to-head matchups, venue performance, and recent form.

### ⚔️ Head to Head Comparison
Compare any two players directly, including a "clutch rating" — how much a player's strike rate changes specifically under pressure, using the same situational logic as the win-probability model itself.

### ⚡ Moment of the Match
The most dramatic mid-innings turnarounds ever recorded, auto-detected and categorized (collapse, assault, squeeze) by the model scanning every ball of every match — no human editor involved.

### 🔀 Rewrite History
Pick a real match, change the outcome of any single ball, and watch the model recalculate everything that follows in real time — a live, interactive demonstration of the model actually understanding game state.

### ℹ️ About / How It Works
A transparent breakdown of every model, dataset, and architectural decision behind the platform.

## Local Setup

### Backend

```bash
cd src
python -m venv venv
venv\Scripts\activate      # Windows
source venv/bin/activate   # macOS/Linux
pip install -r requirements.txt
uvicorn api:app --reload
```

API runs at `http://127.0.0.1:8000` — interactive docs at `http://127.0.0.1:8000/docs`

### Frontend

```bash
cd frontend
npm install
npm run dev
```

App runs at `http://localhost:5173`

Create a `.env` file in `frontend/`:

VITE_API_URL=http://127.0.0.1:8000

## Key Engineering Decisions

- Switched shot-classifier features from raw pose coordinates to normalized joint angles after discovering a real-world domain-shift problem — raised accuracy from 81% to 87%
- Precomputed match replay timelines instead of live recalculation, cutting deployment size from ~273MB to under 1MB per match
- Lazy-loaded the computer vision model stack to keep baseline memory usage low on free-tier hosting
- Added fuzzy name search so all 1,700+ players are findable, not just aliased celebrities

Full write-up of every major decision, bug, and fix: [`docs/decisions.md`](docs/decisions.md)
