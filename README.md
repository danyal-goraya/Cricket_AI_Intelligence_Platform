# Cricket AI Analytics Platform

An AI-powered cricket analytics platform combining match win-probability prediction and computer-vision-based batting shot classification, deployed as a live web application.

## Overview

This project analyzes historical cricket match data to predict live win probability during a match, and uses pose estimation and neural networks to classify batting shot types from images and video. Built as an end-to-end system covering data science, machine learning, computer vision, backend, frontend, and deployment.

## Features (planned)

- Win probability prediction using historical ball-by-ball match data
- Batting shot classification using pose estimation and neural networks
- Web dashboard to view predictions and upload batting clips for analysis

## Tech Stack

- Data Science / ML: Python, Pandas, Scikit-learn, PyTorch
- Computer Vision: MediaPipe
- Backend / API: FastAPI, Laravel
- Frontend: React
- Deployment: Render, Railway, Vercel

## Project Status

In active development. Currently building the data pipeline and win probability model.

## Setup Instructions

1. Clone this repository

git clone https://github.com/danyal-goraya/Cricket_AI_Project.git

2. Navigate into the project folder

cd Cricket_AI_Project

3. Create a virtual environment

python -m venv venv

4. Activate it on Windows PowerShell

venv\Scripts\Activate.ps1

5. Install dependencies

pip install -r requirements.txt
